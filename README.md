# 🎬 Кинотека (React SPA)

Проект разработан в рамках лабораторных работ по изучению библиотеки React, управления глобальным состоянием и маршрутизации. Приложение представляет собой каталог фильмов и сериалов с использованием данных Kinopoisk API Unofficial.

**Ссылка на репозиторий GitHub:** [https://github.com/furdzinartem-prog/kinoteka](https://github.com/furdzinartem-prog/kinoteka)

## 🛠 Запуск проекта на новом устройстве

Чтобы развернуть проект на другом ноутбуке для демонстрации, выполните следующие шаги в терминале:

1. **Склонируйте репозиторий:**
   ```bash
   git clone [https://github.com/furdzinartem-prog/kinoteka.git](https://github.com/furdzinartem-prog/kinoteka.git)
Перейдите в папку проекта:

Bash
cd kinoteka
Установите все необходимые зависимости (React, Redux, Router):

Bash
npm install
Запустите локальный сервер:

Bash
npm run dev
Откройте в браузере ссылку, которая появится в терминале (обычно http://localhost:5173/).

⚙️ Стек технологий и реализованные функции
React + Vite: Быстрая сборка и отрисовка компонентов.

React Router v6: Маршрутизация без перезагрузки страницы (SPA).

/ — Главная страница (каталог и поиск).

/favorites — Страница избранного.

* — Страница 404 (обработка неизвестных адресов).

Redux Toolkit: Глобальное хранилище (store). Управляет добавлением карточек в «Избранное» и переключением типа контента (Фильмы / Сериалы) из шапки сайта.

Архитектура API: Выделенный модуль api.js с единым клиентом fetchClient для подстановки базового URL и API-ключей.

Продвинутый UI:

Фильтрация по жанрам без дополнительных сетевых запросов (derived state).

Модальное окно с детальной информацией, использующее Promise.all для параллельной загрузки описания и списка актеров.
