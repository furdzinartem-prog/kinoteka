## О проекте
**kino.teka** — это веб-приложение каталога фильмов (Single Page Application), разработанное на базе библиотеки React с использованием сборщика Vite. В рамках данной лабораторной работы реализована компонентная архитектура, работа с локальным состоянием и передача данных между компонентами.

## Реализованный функционал
* **Модульная архитектура:** Интерфейс разбит на независимые и переиспользуемые компоненты (`Header`, `Hero`, `MovieSection`, `MovieCard`).
* **Управление состоянием (State):** Использован хук `useState` для обработки пользовательского ввода в строке поиска.
* **Передача данных (Props):** Настроена передача информации (текстовых данных, массивов и функций-обработчиков) от родительских компонентов к дочерним.
* **Поиск и фильтрация:** Реализована эмуляция поиска по каталогу. При вводе названия система фильтрует тестовый массив данных (mock data) и динамически обновляет отображаемые карточки фильмов и заголовок секции, демонстрируя зависимость нескольких компонентов от одного состояния.

## Стек технологий
* React 18
* JavaScript (ES6+)
* Vite
* CSS3 (Flexbox/Grid Layout)

## Запуск проекта на локальной машине

1. Клонируйте репозиторий:
   ```bash
   git clone [https://git.csc.sibsutis.ru/iv523s20/kinoteka.git](https://git.csc.sibsutis.ru/iv523s20/kinoteka.git)

```

2. Перейдите в папку проекта:
```bash
cd kinoteka

```


3. Установите необходимые зависимости:
```bash
npm install

```


4. Запустите локальный сервер для разработки:
```bash
npm run dev

```


5. Откройте приложение в браузере по адресу `http://localhost:5173`.
